# Keyword Word Cloud / 全刊关键词词云

> OJS **3.5** plugin (`generic` category). Custom plugin, not part of the official plugin gallery.

**EN:** Adds a /wordcloud page that aggregates the keywords of all published articles into an interactive visual cloud; every word links to the search results for that keyword.

**中文：** 新增 /wordcloud 页面，将全刊已发表论文的关键词汇总成可视化词云，每个词都可点击跳转到该关键词的检索结果。

## Install 安装

1. Copy this folder to `plugins/generic/` inside your OJS installation.
2. In the OJS dashboard go to *Settings → Website → Plugins* and enable the plugin.
3. Click the plugin's *Settings* button to configure it.
